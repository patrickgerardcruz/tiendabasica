#  Tienda Básica

Tienda virtual desarrollada con Laravel 12, PHP y MySQL,
pensada para pequeños negocios que desean mostrar sus
productos y vender por Internet.

##  Demo en línea

Puedes visitar el proyecto aquí:

https://tiendabasico.infinityfree.me/

##  Características principales

- Tienda virtual con catálogo de productos.
- Administración y publicación de nuevos productos.
- Compras en línea para los clientes.
- Base de datos MySQL.
- Interfaz web para consultar los productos.

## Tecnologías utilizadas

- PHP
- Laravel 12
- MySQL
- HTML5
- CSS3
- JavaScript

## Objetivo del proyecto

Desarrollar una tienda virtual que permita a los
pequeños negocios presentar sus productos en Internet
y ofrecer a sus clientes una forma sencilla de comprar.
